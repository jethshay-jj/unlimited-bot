# UNLIMITED - Bot para Albion Online

## 🚀 Características
- Registro de jugadores con API Albion
- Sistema de reputación meritocrático
- Nominaciones VIP con votaciones (25%)
- Gestión de creadores de contenido
- Reportes con sistema de testigos (2 confirmaciones)
- Leyenda del Mes (automático)
- Escudo del Novato (<7 días protegidos)
